Features

Everything you need.
Nothing you don't.

Built for people who want their TV to work — not to sell them things.

Instant navigation

Smooth, zero-lag app scrolling with a TV remote. Custom recycling shelf built from scratch.

Button shortcuts

Built-in button shortcut mapper that works directly on the home screen. No Accessibility Service required.

Hide & reorder apps

Hide apps you never use, reorder the rest freely. Your home screen, your way.

Zero telemetry

No analytics, no crash reporting, no background network calls. Your usage stays on your device.

Wallpaper support

Full wallpaper support with hardware bitmap config — saves 8–32 MB of RAM compared to software rendering.

Locale-aware clock

Clock with day-of-week prefix in any language. Refreshes immediately on timezone and time changes.

Wi-Fi shortcut

One-press Wi-Fi pill on the home screen for quick network access.

Cold-start cache

Wallpaper, shelf, and icons all paint in the very first frame on every cold start after the first launch.

Under the hood

Built to be tiny
by design.

  • Zero runtime AndroidX dependencies — no AppCompat, Material, RecyclerView, ConstraintLayout, or Lifecycle.
  • Programmatic UI — no XML layouts, no inflated resource bloat. Everything drawn in code.
  • Custom recycling shelf instead of RecyclerView — tight control, zero dependency overhead.
  • R8 minification and resource shrinking on every release build. Dead code has nowhere to hide.
  • Pure Java — no Kotlin standard library shipped. APK stays lean.
  • No native code, no lib/ folder — the same universal APK runs on every architecture.

Getting started

Sideload in minutes.

Not on the Play Store or Amazon Appstore — sideload only.

01

Download the APK

Open the latest release and download BareLauncher-<version>.apk.

02

Transfer to your TV

Use a USB stick, network share, or a sideload tool like Send Files To TV or Downloader.

03

Allow unknown sources

When prompted, allow installs from unknown sources for your file manager or browser.

04

Install the APK

Tap the APK file and press Install. BareLauncher will appear in your app list.

05

Set as default launcher

Use Launcher Manager (XDA) — recommended for Google TV, Android TV, and Fire TV.
